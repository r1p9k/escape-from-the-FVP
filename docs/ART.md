# Вимоги до графіки «Втеча від FPV»

Цей документ описує, які картинки потрібні грі і в якому вигляді. За ним можна генерувати зображення в Gemini (чи іншому генераторі), а потім вставляти їх у гру замість намальованих кодом фігур.

## 1. Загальні правила

- **Вигляд строго збоку** (як у класичних 2D-платформерах), без перспективи й без нахилу камери. Земля — горизонтальна лінія внизу кадру.
- **Стиль**: плоска векторна ілюстрація, чіткі силуети, приглушена «польова» палітра (оливковий, хакі, землисто-коричневий, сірий бетон). Без фотореалізму, без текстур із шумом, без написів і логотипів.
- **Світло** — зверху зліва, однакове на всіх картинках. Тіні м'які, лише всередині об'єкта (без тіні на землі — її малює гра).
- **Об'єкти — PNG із прозорим фоном**, обрізані впритул до силуету (поля не більше 2 px). Фони — PNG або JPG без прозорості.
- **Масштаб**: у грі 1 «одиниця» світу ≈ 1 px на екрані 480 px заввишки. На Full HD екран показує ~2,25 px на одиницю, тому **малюйте в 3× розмірі** від розмірів у таблицях нижче (людина 56 од. → 168 px заввишки).
- **Опорна точка** об'єкта — середина нижнього краю (там, де він стоїть на землі). Низ об'єкта має бути рівним, без «повітря» знизу.
- **Однаковий стиль для всього набору**: одна палітра, одна товщина контуру (або без контуру для всіх), однаковий рівень деталізації.
- Усе має бути **оригінальним**: без персонажів, техніки чи емблем з існуючих ігор, фільмів, армій; без реальних розпізнавальних знаків.

## 2. Фони (паралакс)

Для кожної з трьох тем: **поля**, **лісосмуги**, **зруйноване місто**.

| Шар | Що на ньому | Розмір файлу | Особливості |
|---|---|---|---|
| Небо | Плавний градієнт згори вниз, легкі хмари | 1920×1080 | Не повторюється по горизонталі, розтягується |
| Дальній план | Пагорби / дальня лісосмуга / силует міста в серпанку | 4096×1024 | **Безшовний по горизонталі** (лівий край стикується з правим). Низ — суцільна заливка кольором серпанку |
| Ближній фон | Окремі дерева, стовпи, руїни, огорожі — за ігровим шаром | 4096×1024 | Безшовний по горизонталі, низ прозорий або однотонний |
| Земля (текстура) | Ґрунт у розрізі: трава зверху, нижче земля, глибше темний ґрунт | 1024×512 | **Безшовна по горизонталі й вертикалі**. Верхні ~40 px — трава (окремий шар-смуга 1024×64 з прозорим верхом) |

Кольори тем (як зараз у грі — орієнтир для палітри):

| Тема | Небо (верх → низ) | Дальній план | Трава | Земля |
|---|---|---|---|---|
| Поля | `#8fb8dc` → `#e9e1c4` | `#97a982`, `#b5bf9c` | `#6c8d3a` | `#5d4a30` |
| Лісосмуги | `#7f9db2` → `#d3d9cb` | `#56704f`, `#7c9172` | `#4d6e33` | `#4a3b28` |
| Місто | `#8f9296` → `#d8ccb9` | `#73767c`, `#9a9a9a` | `#6b6a5b` | `#55504a` |

Дальні шари рухаються повільніше за гравця (0,2–0,3 його швидкості), тому на них не повинно бути дрібних деталей, які «мерехтять».

### Будівлі (місто)

- Модульний набір, щоб збирати будинки шириною 200–360 і висотою 1–4 поверхи (поверх = 110):
  - стіна поверху з вікном (вибитим), з дверним прорізом, суцільна, з проломом — кожна 110 заввишки, ширина 60–120;
  - перекриття (плита 10 завтовшки, можна з дірою);
  - дах цілий і з проломом;
  - внутрішній фон кімнати (темніший, видно крізь вікна);
  - драбина 20×110.
- Будівлі напівзруйновані, але без пожеж і без написів.

## 4. Техніка

Усі — вигляд збоку, дивляться **праворуч** (гра віддзеркалює сама). Колеса — окремими картинками (обертаються).

| Техніка | Розмір | Стани |
|---|---|---|
| Мотоцикл | 58×32 | цілий, знищений (обгорілий) |
| Квадроцикл | 62×34 | цілий, знищений |
| Багі | 80×40 | цілий, з кулеметом на турелі, знищений |
| Автомобіль (пікап) | 100×46 | цілий, з кулеметом у кузові, пошкоджений, знищений |
| Кулемет на турелі | 30×10 | окремо, обертається навколо точки кріплення |

## 5. Персонажі

### Людина

Розміри хітбоксів: стоїть 18×56, присіла 20×38, лежить 46×16. Малювати в 3× (стоїть ≈ 168 px). Дивиться **праворуч**.

Потрібні **спрайт-листи** (кадри однакового розміру в один рядок):

| Анімація | Кадрів | Примітки |
|---|---|---|
| Стоїть | 2 | Легке «дихання» |
| Біг | 8 | Цикл |
| Присів, крок | 6 | Цикл |
| Лежить, повзе | 6 | Цикл |
| Кидок на землю | 4 | Від бігу до лежання |
| Лізе драбиною | 4 | Цикл, вигляд збоку/зі спини |
| Прицілювання | 1 тіло + **окремо рука зі зброєю** | Рука обертається навколо плеча |
| Загинув | 1 | Лежить |
| Залазить у нору | 4 | Головою вперед униз |

- **Шолом окремим шаром** (сірий/білий), щоб гра фарбувала його в колір гравця.
- **Бронежилет окремим шаром** поверх тулуба (для кожної пози).
- Без національних шевронів і реальних емблем.

### FPV-дрон

- Корпус 28×14, вигляд збоку, з бойовою частиною знизу.
- Гвинти окремо: «розмиті» (летить) і нерухомі (стоїть на землі).
- Невелика кольорова смужка на корпусі — окремим шаром (колір гравця).

## 7. Як передавати файли

- Назви латиницею: `bg_fields_far.png`, `obj_hay_1.png`, `veh_buggy_mg.png`, `human_run.png`, `fx_explosion.png`.
- Окремі папки: `art/backgrounds`, `art/objects`, `art/vehicles`, `art/characters`, `art/fx`.
- Для спрайт-листів напишіть кількість кадрів і розмір одного кадру.
- Почніть з одного набору (наприклад, тема «поля» + людина + дрон). Я під'єднаю його до гри й підлаштую масштаб, після чого можна генерувати решту.

## 8. Шаблон запиту для Gemini

Підставляйте свій об'єкт замість `[ОБ'ЄКТ]`:

> Flat 2D vector game asset, strict side view (orthographic, no perspective), [ОБ'ЄКТ], muted field palette (olive, khaki, earthy brown, concrete grey), soft light from top-left, clean silhouette, no outline, no text, no logos, no insignia, isolated on a transparent background, centered, bottom edge flat on the ground line, consistent style for a 2D side-scrolling game.

Для фонів:

> Seamless horizontally tileable 2D side-scrolling game background layer, flat vector style, [ПОЛЯ / ЛІСОСМУГА / ЗРУЙНОВАНЕ МІСТО] far in the distance, atmospheric haze, muted palette, no characters, no text, 4096×1024, the left and right edges must match perfectly.

Для спрайт-листів:

> 2D game sprite sheet, side view facing right, [N] frames in one row, equal frame size [W×H] px, [АНІМАЦІЯ, напр. soldier running cycle], flat vector style, muted olive uniform, grey helmet (to be tinted), no insignia, transparent background.

Генератори часто не тримають точний розмір і безшовність. Якщо краї фону не стикуються або кадри різного розміру, я це виправлю під час під'єднання, але чим ближче до вимог, тим краще.
